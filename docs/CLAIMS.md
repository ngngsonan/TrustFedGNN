# Claim ledger

Every number in the article's abstract, text, tables and conclusion, with the artifact it comes from and the command that recomputes it. All paths are under `results/campaigns/`. `A` stands for `analysis/discover_ai.json`, which is written by

```bash
python -m experiments.campaigns.analyze_discover_ai
```

Tables are generated by `python -m experiments.campaigns.make_tables`. Each caption claim is checked with `require(...)` against the same numbers; with the manuscript sources present, `--check` diffs the output with `manuscript/tables/`.

## Evidence deliberately not used

| Item | Reason |
|---|---|
| `C20a_fixed_state_replay.json` | Superseded by C20r. It injected no falsified report into the report-free rules and did not seed each run. Kept for transparency; C20r stores its SHA-256 under `supersedes`. |
| C24 reference evasion × FedAvg, original 20 runs | The adversaries' report omitted the sample count that FedAvg reads (`aggregate` defaults it to 1). C24r re-ran exactly these runs in the C24 environment with the true count; `load_c24()` substitutes them. Before C24r ran, one stored C24 cell was re-run there and matched bit for bit. The other methods do not read `n` (`tests/test_campaigns.py`), so their cells are unchanged. |
| C20b/c q-FFL-eq arm | Its update norm is about 10⁻³ of root-FLTrust's and its clean AUC is near chance (0.54 German, 0.51 Bail), so its weight shift is not used as evidence. |
| C23 per-round `I_adv` field | Written before the mechanism logger fix; it holds the adversarial weight. Processed influence is taken from C23b and C24. |
| C05 FLTrust arm | Uses the earlier gradient reference, not the root update. |
| C20r `qffl` | A seventh report-dependent rule (plain q-FFL). It responds in 25/30 seeds, but its weights are NaN at round 0 in seeds 43, 52, 56, 58 and 67, so its mean is undefined; the table reports the finite variant `qffl_eq`. |
| C20r `fu_shapley_alpha0` | FU-Alignment without the fairness term; invariant in 30/30 seeds like the canonical rule, so it is not shown separately. |
